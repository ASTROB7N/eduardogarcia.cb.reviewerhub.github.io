Lesson 1: Introduction to Java, JDK, JRE, and JVM

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible. It is a general-purpose programming language intended to let programmers write once, run anywhere (WORA).

Core Components

  • JVM (Java Virtual Machine): An abstract machine that enables your computer to run a Java program by converting bytecode into machine-specific instructions.
  • JRE (Java Runtime Environment): A software package that provides the class libraries and other components required to run Java programs. JRE = JVM + Core Classes.
  • JDK (Java Development Kit): A software development environment used to develop Java applications and applets. JDK = JRE + Development Tools (compiler, debugger).

Basic Java Program Structure

public class Main { public static void main(String[] args) { System.out.println("Hello, Java!"); } }

Lesson 2: Variables and Data Types

Variables are containers for storing data values. In Java, variables must be declared with a specific data type.

Primitive Data Types

  • byte: 8-bit signed integer (-128 to 127)
  • short: 16-bit signed integer
  • int: 32-bit signed integer (Default for integers)
  • long: 64-bit signed integer (suffixed with 'L')
  • float: 32-bit floating-point (suffixed with 'f')
  • double: 64-bit floating-point (Default for decimals)
  • char: 16-bit Unicode character
  • boolean: true or false

Reference Data Types

Reference data types store references to objects (e.g., Strings, Arrays, Classes). Strings are objects enclosed in double quotes.

int age = 25; double salary = 45000.50; char grade = 'A'; boolean isJavaFun = true; String name = "Alice";

Lesson 3: Operators & Expressions

Operators are used to perform operations on variables and values.

  • Arithmetic Operators: `+`, `-`, `*`, `/`, `%` (Modulo returns remainder).
  • Relational Operators: `==`, `!=`, `>`, `<`, `>=`, `<=`. Returns boolean.
  • Logical Operators: `&&` (AND), `||` (OR), `!` (NOT).
  • Unary Operators: `++` (Increment), `--` (Decrement). Pre-increment (`++x`) vs Post-increment (`x++`).

Lesson 4: Control Flow (If-Else Statements)

Conditional statements allow your program to make decisions based on boolean expressions.

int score = 85; if (score >= 90) { System.out.println("Grade: A"); } else if (score >= 75) { System.out.println("Grade: B"); } else { System.out.println("Grade: C"); }

Lesson 5: Switch Statements & Loops

Switch Statement

Selects one of many code blocks to be executed based on variable equality.

int day = 2; switch (day) { case 1: System.out.println("Monday"); break; case 2: System.out.println("Tuesday"); break; default: System.out.println("Other day"); }

Loops

  • For Loop: Used when the number of iterations is known.
  • While Loop: Repeats while a condition remains true, checked before execution.
  • Do-While Loop: Executes at least once before checking the condition.
// For loop example for (int i = 1; i <= 3; i++) { System.out.print(i + " "); } // Output: 1 2 3

Lesson 6: Arrays (1D and 2D)

Arrays are used to store multiple values in a single variable, instead of declaring separate variables for each value.

// 1D Array declaration and initialization int[] numbers = {10, 20, 30, 40}; System.out.println(numbers[1]); // Output: 20 // 2D Array (Matrix) int[][] grid = { {1, 2}, {3, 4} }; System.out.println(grid[1][0]); // Output: 1

Lesson 7: Methods and Parameters

A method is a block of code which only runs when it is called. You can pass data, known as parameters, into a method.

public class Test { public static int add(int a, int b) { return a + b; } public static void main(String[] args) { int result = add(5, 10); System.out.println(result); // Output: 15 } }

Lesson 8: Object-Oriented Programming (OOP)

Java is an object-oriented language centering around classes and objects.

  • Class: A blueprint for creating objects.
  • Object: An instance of a class containing state (fields) and behavior (methods).
  • Inheritance: Mechanism where one class acquires the properties of another using the `extends` keyword.
  • Polymorphism: Ability of an object to take on many forms (Method overloading and overriding).

Part 1: Introduction to Advanced Multimedia

Basic vs. Advanced Multimedia

  • Basic Multimedia: The combination of text, images, audio, video, and animation into a single interactive presentation (e.g., PowerPoint presentations, simple web pages, basic video editing).
  • Advanced Multimedia: Goes beyond basic integration by incorporating cutting-edge technologies, interactivity, immersive experiences, and complex processing techniques to create dynamic content.

Key Features of Advanced Multimedia

  • Real-time Interactivity: Users interact with content and see immediate responses/changes (e.g., video games).
  • 3D Modeling & Animation: Creating 3D digital objects and making them move (e.g., Pixar or DreamWorks films).
  • Virtual Reality (VR) & Augmented Reality (AR): VR creates a fully computer-generated environment explored via headsets; AR overlays digital content onto the real world using smartphones or glasses.
  • Adaptive & Personalized Content Delivery: Customizes content based on user preferences, behavior, or device (e.g., Netflix recommendations, adaptive e-learning).
  • Motion Graphics & Special Effects (VFX): Animated graphic design elements and visual illusions in film/video (e.g., CGI, animated infographics).

Components of Advanced Multimedia (NACES MAPICS)

  • Text & Typography: Advanced text effects, kinetic typography (moving text synchronized with audio), and 3D text animations.
  • Images & Graphics: Scalable vector graphics (e.g., Adobe Illustrator), 3D rendering, and image manipulation.
  • Audio: Surround sound, audio mixing, and spatial audio for VR that changes based on where you look.
  • Video: 4K/8K ultra-high resolution, special effects, and chroma keying (green screen background replacement).
  • Animation: 2D animation, 3D animation, and motion capture (recording actor movements for 3D characters).
  • Interactivity: User-controlled navigation menus and interactive simulations/games.
  • Emerging Tech: VR, AR, XR (Extended Reality combining VR, AR, and MR), and 3D floating holograms.

Part 2: Photo Editing & Manipulation

Photo Editing vs. Photo Manipulation

  • Photo Editing: Enhancing or correcting an image while keeping it close to reality.
    • Goals: Making photos cleaner, sharper, and visually appealing via color correction, cropping, resizing, and sharpening/noise reduction.
  • Photo Manipulation: Transforming, combining, or creating images that go beyond reality.
    • Goals: Telling a new visual story through compositing, surreal effects, digital artwork, and special effects like glitch art or neon effects.

Core Concepts & Techniques

1. Retouching Techniques (Cleaning up details)

  • Spot Healing Brush / Healing Tool: Removes small imperfections by blending surrounding pixels.
  • Clone Stamp Tool: Copies pixels from one area to another to remove large objects or duplicate textures.
  • Frequency Separation: Separates texture (pores, wrinkles) from color/tone to smooth skin naturally without a "plastic" look.

2. Color Grading (Adjusting overall mood or atmosphere)

  • Adjustment Layers: Non-destructive edits for brightness, hue, saturation, and exposure.
  • Curves / Levels: Fine-tunes shadows, midtones, and highlights for balanced contrast.
  • Color Balance / Selective Color: Adds creative tones (warm, cool, cinematic).

3. Layer Masking & Blending Modes

  • Layer Masking: Hides or reveals parts of a layer like "painting" with visibility. Non-destructive editing.
  • Blending Modes: Controls how layers interact (e.g., Multiply darkens, Screen brightens, Overlay enhances contrast).

4. Compositing

  • Merging multiple images seamlessly. Requires perspective matching, lighting adjustments, and careful masking.

5. Special Effects

  • Double exposure, surrealism, and glitch art to create abstract or striking artwork.

Part 3: Advanced Video Editing

What is Video Editing?

The process of arranging, cutting, and enhancing video clips to tell a story or deliver a message across films, ads, vlogs, and education.

Stages of Video Editing

  • Importing Media: Adding video, audio, and images into the software.
  • Arranging on Timeline: Organizing clips in sequence.
  • Cutting & Trimming: Removing unwanted parts.
  • Adding Effects & Transitions: Making clips flow smoothly.
  • Text & Titles: Inserting captions, credits, and subtitles.
  • Audio Editing: Adding background music or voiceovers.
  • Exporting: Saving the video in the correct format (MP4, AVI, MOV).

Tools in Video Editing Software

  • Timeline/Tracks: Where video and audio clips are arranged.
  • Cut/Split Tool: Trims video.
  • Effects Library: Visual effects and transitions.
  • Audio Mixer: Adjusts sound levels.
  • Export/Render Button: Saves the final video.

Advanced Editing Techniques

  • Multi-layer Editing: Using multiple video/audio layers for picture-in-picture or green screen overlays.
  • Color Grading & Correction: Adjusting brightness, contrast, saturation, color balance, and applying LUTs (Look-Up Tables) for a cinematic style.
  • Keyframing & Animation: Creating smooth motion for text, images, and effects (e.g., zooming in or moving titles).
  • Transitions & Special Effects: Glitch effects, whip pans, speed ramping, and chroma keying.
  • Audio Enhancement: Audio equalization, noise reduction, beat syncing, and voice-over adjustments.
  • Exporting & Rendering Settings: Choosing proper resolution (1080p, 4K), formats (MP4, MOV, AVI), and adjusting bitrate/compression for online sharing.

Chapter 1: Introduction to Information Management (DBMS)

What is a Database?

“A database is an organized collection of related data, stored electronically, so it can be easily accessed, managed, and updated.”

  • Organized: Structured data — usually in tables of rows and columns.
  • Electronic: Stored on a computer or server, searchable instantly.
  • Shared & Manageable: Many users and programs can safely access the same data.

Data vs. Information

  • Data: Raw, unprocessed facts. Has little meaning alone. Example: 19, “Maria”, “BSIT”, 95, 88, 91 (raw scores).
  • Information: Data that has been processed and organized so it becomes meaningful. Example: “Maria, 19, is a BSIT student”, “Class average: 91.3”.

Note: A database stores data — but its real purpose is turning that data into useful information.

Databases Around You

  • School Enrollment: Student records, grades, and class schedules.
  • Online Shopping: Products, prices, stock, and order history.
  • Mobile Banking: Account balances and transaction history.
  • Social Media: Posts, photos, and friend connections.
  • Hospital Records: Patient history and appointment schedules.
  • Library Catalog: Book titles, authors, and borrower records.

File System vs. Database

Traditional File System

  • Data stored in separate flat files. Each program keeps its own copy.
  • No easy way to link related files.
  • Problems:
    • Data Redundancy: The same data gets typed and stored in many separate files.
    • Data Inconsistency: One copy is updated but another isn't, so records contradict each other.
    • Poor Security: Flat files are hard to protect from unauthorized access.

Database (DBMS)

  • Data stored centrally in one system. Multiple programs share one source of truth.
  • Key Benefits:
    • Improved Consistency & Reduced Redundancy: Update once — everyone sees it instantly.
    • Data Integrity: A DBMS enforces rules so invalid data cannot be saved (e.g., blocking a grade of "950").
    • Access Control: Only authorized users can view or edit specific data.
    • Backup & Recovery: Can restore data after a crash or power loss.
    • Multi-User Access & Concurrency Control: Many people can use it simultaneously without overwriting each other's work.

Common Types of Databases

  • Relational (RDBMS): Tables of rows & columns. Example: MySQL.
  • NoSQL / Document: Flexible records. Example: MongoDB.
  • Hierarchical: Tree-like parent-child structure.
  • Network: Records linked in a web, not just a tree.
  • Cloud Database: Hosted online. Example: Firebase.
  • In-Memory Database: Kept in RAM for speed. Example: Redis.

What is SQL?

“SQL is the standard language used to create, read, update, and manage data in a relational database.” It is Standardized, Declarative (you describe what you want; the DBMS handles how), and Readable.

  • DDL (Data Definition Language): Defines structure: CREATE, ALTER, DROP.
  • DML (Data Manipulation Language): Works with data: SELECT, INSERT, UPDATE, DELETE.
  • DCL (Data Control Language): Manages permissions: GRANT, REVOKE.
  • TCL (Transaction Control Language): Manages transactions: COMMIT, ROLLBACK.

What is an RDBMS?

“An RDBMS is software that stores data in related tables and lets users manage it using SQL.”

  • Tables / Relation / Entity: Made up of Rows (Record / Tuple) and Columns (Field / Attribute).
  • Primary Key: Uniquely identifies each row. Cannot be duplicated or empty.
  • Foreign Key: Links to another table's primary key to connect related tables.

Types of Table Relationships

  • One-to-One (1:1): One student, one ID card record.
  • One-to-Many (1:N): One professor teaches many sections.
  • Many-to-Many (M:N): Many students enroll in many subjects.

Chapter 1: SQL Practice

STEP 1: CREATE DATABASE

Before any table can exist, the database itself has to be created.

-- Create a new database for the school system
CREATE DATABASE school_system;

-- Switch to using it
USE school_system;
  • CREATE DATABASE: asks the DBMS to allocate a new, empty database. No tables or data exist inside it yet.
  • USE: tells the server that every statement from here on applies to this database. Analogy: building a new filing cabinet vs. opening it.

STEP 2: CREATE TABLE

Defines a new table's columns and the data type each one holds.

CREATE TABLE courses (
  course_id INT PRIMARY KEY,
  course_name VARCHAR(50),
  units INT,
  instructor VARCHAR(50)
);
  • INT PRIMARY KEY: a unique whole-number ID; no two rows can share it, and it can't be blank.
  • VARCHAR: text fields.

Linking Tables with Foreign Keys

CREATE TABLE enrollments (
  enrollment_id INT PRIMARY KEY,
  student_id INT,
  course_id INT,
  semester VARCHAR(20),
  grade DECIMAL(4,2),
  FOREIGN KEY (student_id) REFERENCES students(student_id),
  FOREIGN KEY (course_id) REFERENCES courses(course_id)
);
  • DECIMAL(4,2): a decimal with up to 4 digits total and 2 after the point, e.g. 91.50.
  • FOREIGN KEY... REFERENCES: connects students and courses without duplicating their data. Every ID here must already exist in the parent table.

STEP 3: ALTER TABLE

Changes a table's structure after it already exists — no rebuild needed.

  • ADD: `ALTER TABLE students ADD email VARCHAR(100);` adds a brand-new column. Existing rows get NULL.
  • MODIFY: `ALTER TABLE students MODIFY full_name VARCHAR(100);` resizes the column to hold longer names.
  • CHANGE: `ALTER TABLE students CHANGE course program VARCHAR(255);` keeps the same data and type — only the column's name changes.
  • DROP COLUMN: `ALTER TABLE students DROP COLUMN email;` permanently deletes that column and every value stored in it.

STEP 4: UPDATE

A DML command: it changes data, not structure. WHERE decides which rows are affected.

UPDATE students
SET course = 'BSCS', year_level = 2
WHERE student_id = 105;
  • Multiple columns can be set at once, separated by commas.
  • WHERE: limits the change. If you skip WHERE, every single row is updated. The WHERE clause can also target an entire group (e.g. `WHERE year_level = 4`).

STEP 5: DELETE

Removes entire rows. Like UPDATE, WHERE controls which ones are affected.

  • `DELETE FROM students WHERE student_id = 101;` restricts deletion to one row.
  • `DELETE FROM students WHERE course = 'BSHM';` deletes every row sharing that condition.
  • `DELETE FROM enrollments;` (No WHERE clause) removes every row. The table, its columns, and structure remain — it's just empty. This is different from DROP TABLE which deletes the structure entirely.

Chapter 1: Introduction to Data Structure

What is Data?

  • Factual information (such as measurements or statistics) used as a basis for reasoning, discussion, or calculation.
  • A collection of facts and figures or a set of values or values of a specific format that refers to a single set of item values.

What is Data Structure?

A branch of Computer Science that allows us to understand the organization of data and the management of the data flow in order to increase the efficiency of any process or program. Data Structure is a particular way of storing and organizing data in the memory of the computer so that these data can easily be retrieved and efficiently utilized in the future when required.

Note: The data structure is not any programming language like C, C++, java, etc. It is a set of algorithms that we can use in any programming language to structure the data in the memory.

  • Examples of Data Structures include Arrays, Linked List, Stack, Queue, etc.
  • Data Structures are widely used in almost every aspect of Computer Science (i.e. Operating System, Compiler Design, Artificial intelligence, Graphics etc.).

Why do we need Data Structure?

As applications are getting complex and the amount of data is increasing day by day, problems may arise:

  • Processor speed: To handle very large amount of data, high speed processing is required, but as data grows to billions of files per entity, processor may fail. Each data structure allows data to be stored in a specific manner.
  • Data Search: Consider an inventory size of 10^6 items in a store; searching a particular item by traversing 10^6 items every time results in slowing down the search process. Data Structure allows efficient data search and retrieval.
  • Multiple requests: If thousands of users are searching data simultaneously on a web server, there are chances that a very large server can fail. Data structures allow managing large amounts of data such as large databases and indexing services.

Objectives of Data Structure

Data Structures satisfy two complementary objectives:

  • Correctness: Designed to operate correctly for all kinds of inputs based on the domain of interest.
  • Efficiency: Efficiency of a program depends upon the choice of data structures (e.g., searching in an ordered array, binary search tree, or hash table is more efficient than scanning a standard array sequentially).

Key Features of Data Structures

  • Robustness: Software must yield correct output for every possible input, along with efficient execution on all hardware platforms, managing both valid and invalid inputs.
  • Adaptability: Large software systems like Web Browsers, Word Processors, and Internet Search Engines require correct execution for many years and must evolve due to emerging technologies or ever-changing market conditions.
  • Reusability: If software is developed in a reusable and adaptable way, it can be applied in most future applications, appearing cost-effective and timesaving.

Classification of Data Structures

We can classify Data Structures into two categories:

  • Primitive Data Structure: Primitive data types (int, char, float, double, and pointer which can hold a single value).
  • Non-Primitive Data Structure: Divided into Linear and Non-linear data structures.
    • Linear Data Structures: All elements arranged in a linear order, stored in a nonhierarchical way where each element has successors and predecessors (except first and last). Examples: Arrays, LinkedList, Stack, Queue.
    • Non-Linear Data Structures: Does not form a sequence; each element is connected with two or more other items in a non-linear arrangement. Examples: Trees, Graphs.

Chapter 2: Operations and Algorithms

What is an Operation?

In order to process elements of a data structure some kind of operation is required. It is the way parts of a machine or system work together, or a mathematical process in which one set of numbers is produced from another.

  • Creation & Deletion: Creation reserves memory (at compile-time or run-time), while deletion removes items and releases allocated storage space. (Creation and deletion are the two fundamental operations).
  • Other Common Operations: Traversing, Searching, Insertion, Deletion, Sorting, Merge, Selection, Update, Splitting.

The Operations List

  • Traversing: Accessing each data element exactly once so it can be administered (e.g., printing names of all employees).
  • Searching: Finding the location of one or more data elements that meet certain constraints.
  • Insertion: Inserting or adding new data elements to the collection.
  • Deletion: Removing or deleting a specific data element from the given list.
  • Sorting: Arranging data elements in either Ascending or Descending order.
  • Merge: Combining data elements of two sorted lists in order to form a single list of sorted data elements.
  • Create: Reserving memory for data elements using declaration statements during compile-time or run-time.
  • Selection: Selecting particular data by specifying conditions inside a loop.
  • Update: Modifying the data in the data structure by specifying conditions inside a loop.
  • Splitting: Dividing data into various subparts decreasing the overall process completion time.

What is an Algorithm?

An algorithm is a process or a set of rules required to perform calculations or some other problem-solving operations especially by a computer. It contains a finite set of instructions carried out in a specific order to perform a specific task. It is not the complete program or code; it is just a solution (logic) represented as a Flowchart or Pseudocode.

Flowchart and Pseudocode

  • Flowchart: A diagram depicting a process, system or computer algorithm.
    • Terminator (Oval): Starting or ending point.
    • Action / Process (Rectangle): Indicates a particular operation.
    • Decision (Diamond): Decision or branching point leading to different situations.
    • Data or Input/Output (Parallelogram): Information entering or leaving the system.
    • Flow (Lines): Sequence and direction of a process.
  • Pseudocode: An informal high-level representation of actual code showing how an algorithm or computer program works in plain English. It cannot be compiled into an executable program.
set i to 0 for each i from 0 to 9 if i is odd print i end for loop

Characteristics of an Algorithm

  • Input: Inputs to a set of rules must be well-described.
  • Output: Results should be exactly what is expected.
  • Unambiguity: Instructions should be clear and simple.
  • Finiteness: A finite number of steps is required to reach its end state.
  • Feasibility / Effectiveness: Probably doable with the tools at hand.
  • Language Independent: Instructions written out in detail, separate from actual code.

Dataflow & Why We Need Algorithms

Dataflow is the movement of data through software/hardware. The movement sequence is: Problem -> Algorithm -> Input -> Processing Unit -> Output.

We need algorithms because of Scalability (breaking down big real-world problems into small steps) and Performance (measuring if a problem is feasible).

Algorithm Complexity

Algorithm performance is measured in two factors using Big O notation (part of Bachmann–Landau asymptotic notation):

  • Time Complexity: Amount of time required to complete execution, calculated by counting the number of steps.
  • Space Complexity: Amount of space required to solve a problem and produce output. Space is needed to store program instructions, constant values, variable values, and track function calls/jumping statements.
  • Auxiliary Space: The extra space required by the algorithm excluding input size. Thus, Space complexity = Auxiliary space + Input size.

Module 1: Introduction to Ethics

Course Code: EHICS 203  |  Prepared by: Maybhel C. Hernandez, LPT  |  Pampanga State University (Candaba Campus)

Objectives

  • Differentiate between ethics and morality by examining definitions, examples, and real-life scenarios.
  • Identify and explain the three main branches of ethical theory—metaethics, normative ethics, and applied ethics—and their practical applications.
  • Evaluate moral dilemmas using various ethical perspectives and theories, including moral realism, subjectivism, emotivism, and prescriptivism.

What is Ethics?

  • Derived from the Greek word "Ethos", meaning character, habit, or disposition. It involves systematizing, defending, and recommending concepts of right and wrong behavior.
  • Ethics is the branch of philosophy that deals with questions about what is morally right and wrong, good and bad, fair and unfair.
  • It involves the study of moral principles and values that guide human behavior and decision-making. It helps individuals and societies determine how they ought to act in various situations, especially when faced with difficult choices or moral dilemmas.
  • Ethics is a moral science.

Ethics vs. Morality

Scenario: Maria is a nurse working in a government hospital. One evening, a wealthy patient offers her a large sum of money in exchange for being prioritized in the treatment queue, despite other patients having waited longer and having more urgent medical needs.

Ethical Perspective: From a professional ethics standpoint, Maria is bound by the code of ethics for nurses, requiring her to treat all patients fairly without bias or favoritism. Accepting the bribe is unethical because it violates justice, fairness, and professional conduct.

Moral Perspective: On a personal level, Maria was raised to always help her family, who are currently struggling financially. Morally, she feels tempted to accept the money because it could pay for her younger sibling's school fees and buy medicine for her ill mother. Her internal values and sense of loyalty to her family conflict with her ethical duty as a nurse.

What is Morality?

  • Refers to the set of personal or societal beliefs about what is right and wrong, good and bad behavior.
  • Shaped by culture, religion, upbringing, personal experiences, and social norms. Unlike formal rules or laws, morality often comes from within—a person's conscience and sense of justice.
  • Morality guides how individuals live in daily life, influencing decisions, actions, and treatment of others (e.g., honesty, showing kindness, helping those in need, respecting others).
  • Morality is the practice of ethics.

What are the Rules?

  • Explicit or understood regulations or principles governing conduct within specific activities or spheres. Serve as a foundation for a healthy society.
  • Meant to ensure order in every organization, whether in a small or large community of people.

Importance of Rules to Social Beings

  1. Rules protect social beings by regulating behavior.
  2. Builds boundaries and places limits on behavior.
  3. Rules help to guarantee each person certain rights and freedom.
  4. Rules produce a sense of justice among social beings.

Use of Rules in Our Lives

  • Etiquette: Standards by which we judge manners to be good or bad, normally dictated by society's economic elite.
  • Legal: Standards by which we judge legal right and wrong in a democracy, formulated by representatives of the people.
  • Athletic: Standards by which we judge how good or bad a game is played, usually formulated by governing bodies.
  • Aesthetic: Standards by which we judge good and bad art, usually dictated by a small circle of art specialists.
  • Language: Standards by which we judge what is grammatically right or wrong evolved through use.

Ethical Theories in Three General Subjects

  • I. Meta-Ethics: Study of characteristics of ethics that deal with the nature of moral judgment. Example: Saying "Lying is morally wrong" means the speaker disapproves of lying.
  • II. Normative Ethics: Concerned with the content of moral judgment and criteria of what is right or wrong. Creates guidelines for moral conduct. Example: Saying a Lexus is a "really nice car", which most people agree with.
Metaethics Normative Ethics
Study of the nature of ethics. Study of ethical action.
Analyzes the meaning of moral language and metaphysics of moral facts. Evaluates standards for the rightness and wrongness of actions.
More philosophical in nature as it analyzes the nature of ethics and morality. More practical in nature.
  • III. Applied Ethics: Deals with difficult moral questions and controversial moral issues faced in life.
    • Examples: Abortion, Euthanasia, Giving to the poor, Sex before marriage, The death penalty, So-called "white lies".

Significance of the Study of Ethics

  • Ethics in Moral Life: To be useful in practice, ethical theories need to affect human behavior. Ethics can provide a moral plan and framework to help navigate difficult issues (e.g., abortion, euthanasia) rather than letting emotions drive decisions.
  • Ethics can identify disagreement: Helps parties arguing a moral issue realize they broadly agree on everything else, taking heat out of arguments and helping resolution.
  • Ethics does not give right answers: Instead of a single right answer, it offers principles for clear choices, eliminates confusion, and leaves final conclusions to individuals.
  • Ethics can give several answers: Addresses human discomfort with moral ambiguity.
  • Ethics is about the "other": Concerned with other people and interests beyond self-interest.
  • Ethics as a source of group strength: Can be misused as a weapon to attack groups practicing activities deemed wrong.
  • Good people as well as good actions: Concerns personal goodness and what it means to live a good life.

Four Ethical "-isms"

  1. Moral Realism: Based on the idea that there are real, objective moral facts or truths in the universe. Moral statements provide factual information about those truths.
  2. Subjectivism: Teaches that moral judgments are nothing more than statements of a person's feelings or attitudes, containing no factual truths about goodness or badness.
  3. Emotivism: View that moral claims are no more than an expression of approval or disapproval (e.g., saying "murder is wrong" while pulling a horrified face).
  4. Prescriptivism: Ethical statements are instructions or recommendations (e.g., "lying is wrong" means people ought not to tell lies).

Module 2: Moral and Non-Moral Standards

Course Code: EHICS 203  |  Prepared by: Maybhel C. Hernandez, LPT

Objectives

  • Explain key characteristics and examples of moral standards, including their focus on ethical principles and impact on human well-being.
  • Identify and describe non-moral standards, highlighting their cultural specificity, situational nature, and differences from moral standards.
  • Differentiate between moral and non-moral standards by comparing their purposes, consequences, and ethical significance.

Introduction

In our daily lives, we are guided by different kinds of rules, principles, and expectations. Some are deeply connected to morality (right or wrong), while others are customs or preferences.

1. Moral Standards

Principles that guide us in distinguishing right from wrong, just from unjust, and good from bad. Deeply rooted in ethics and directly affect how we treat others.

Characteristics:

  • Universal or widely accepted: Apply to all people regardless of culture or background.
  • Concerned with others' well-being: Protect human dignity, rights, and justice.
  • Involve serious consequences: Violating them leads to guilt, social condemnation, or legal punishment.
  • Backed by reason: Supported by ethical reasoning or logical justification.
  • Independent of laws: Some actions may be legal but still immoral (e.g., past racial discrimination).

Examples:

Telling the truth, respecting others' rights, not stealing or cheating, helping someone in need.

2. Non-Moral Standards

Rules that guide behavior but are not directly connected to ethics or morality. Often relate to customs, etiquette, or personal preferences.

Characteristics:

  • Culture-specific or situational: Vary depending on group, context, or tradition.
  • Do not directly affect others' rights or well-being.
  • Less serious consequences: Breaking them may lead to embarrassment or disapproval, but not moral condemnation.
  • Not backed by ethical reasoning: Usually based on style, convenience, or social norms.

Examples:

Dress codes, table manners, business/academic protocols (deadlines, format guidelines), fashion trends.

Key Differences Between Moral and Non-Moral Standards

Aspect Moral Standards Non-Moral Standards
Basis Ethics, right vs. wrong Customs, etiquette, preferences
Scope Universal, affects everyone Culture-specific or situational
Consequence Serious (guilt, punishment, social condemnation) Less serious (embarrassment, social disapproval)
Reasoning Backed by ethical principles Based on style, habit, or tradition

Module 3: Moral Dilemma and Types of Moral Dilemmas

Course Code: EHICS 203  |  Prepared by: Maybhel C. Hernandez, LPT

Objectives

  • Define what a moral dilemma is.
  • Explain the conditions that must be present in a moral dilemma.
  • Identify and describe the different types of moral dilemmas.
  • Differentiate the levels of moral dilemmas (individual, organizational, and structural/macro).
  • Analyze real-life scenarios and determine the type of moral dilemma they represent.

What is a Dilemma?

A situation where a person is forced to choose between two or more conflicting options, neither of which is completely acceptable. When dilemmas involve human actions with moral implications, they are called **ethical or moral dilemmas**.

Example: A deeply religious woman with an ectopic pregnancy faces a conflict: resort to abortion to save her life, or not resort to abortion to keep her belief but risk her life. Both choices compromise important values.

Conditions for a Moral Dilemma

  1. Decision-making is required: The person must choose a course of action.
  2. Conflicting options exist: There must be at least two possible actions.
  3. Moral principles are compromised: No matter the choice, some moral value will be violated.

Types of Moral Dilemmas

  • a. Epistemic Moral Dilemma: Conflict arises because the person does not know which moral requirement should take precedence (lack of complete knowledge). Example: Promising a daughter to come home early, but seeing a sick man needing urgent help on the way.
  • b. Ontological Moral Dilemma: Two or more moral requirements conflict with each other, and neither is stronger than the other.
  • c. Self-Imposed Moral Dilemma: Caused by the wrongdoings or mistakes of the moral agent. Example: Cheating on an exam, then being asked by the teacher to explain how it was solved (lying vs. admitting truth).
  • d. World-Imposed Moral Dilemma: External events or circumstances beyond individual control force a moral conflict. Example: Natural disasters or wars forcing who to save first.
  • e. Obligation Moral Dilemma: Person feels morally obliged to fulfill two or more duties but can only choose one. Example: Having 1 peso left and seeing two donation jars.
  • f. Prohibition Moral Dilemma: All available options are morally wrong, but a choice must still be made. Example: A psychopath telling a parent to kill one child to save the rest.
  • g. Single-Agent Dilemma: The conflict and decision fall on one person only.
  • h. Multi-Agent Dilemma: Decision involves two or more people who must agree or take collective action. Example: A family deciding whether to perform euthanasia on a very sick relative.

Levels of Moral Dilemmas

  1. Individual Level: Problems faced personally by an individual when making difficult moral choices.
    • Example: Heinz Dilemma (Kohlberg, 1958) — Heinz's wife is dying, and he must choose between stealing the drug (morally right, legally wrong) or obeying the law (legal, results in wife's death).
  2. Organizational Level: Dilemmas involving standards, rules, or policies within a workplace or institution. Conflict between personal interests and organizational welfare.
    • Examples: Catholic school dilemma balancing low tuition for the poor against higher salaries to retain qualified teachers; Leadership dilemma (participatory leadership failing, leading to authoritarian rule).
  3. Structural / Macro Level: Moral dilemmas influenced by larger societal or global contexts. Systemic and more complex.
    • Sub-issues: Differentiation vs. Integration (e.g., local governments managing schools vs. national curriculum integration); Centralized vs. Decentralized Decision-Making; World Organizations like the UN (world order vs. national sovereignty).

Module 4: Freedom as a Moral of Choice

Course Code: EHICS 203  |  Prepared by: Maybhel C. Hernandez, LPT

Objectives

  • Explain why freedom is essential for making moral acts.
  • Differentiate between actions made with freedom and actions bound by instinct or compulsion.
  • Understand Immanuel Kant's perspective on free will and moral responsibility.
  • Recognize the importance of observing moral standards instead of following them blindly.
  • Apply the concept of freedom and responsibility to real-life moral dilemmas.

Introduction

Freedom is at the heart of human dignity. Without the capacity to make free choices, a person cannot be truly responsible for their actions. Freedom is the foundation of morality, allowing choices between good and evil, right and wrong.

1. Freedom and Moral Choice

  • Freedom means the ability to make unhindered decisions.
  • Immanuel Kant's Perspective: Free will is necessary if we are to be held morally responsible for our actions. If an external force determined all choices, actions could not be judged as moral or immoral, and praise/blame would lose meaning.
  • Key Point: To be responsible is to be free. Only free beings (humans) can be held accountable for their choices.

2. Human Freedom vs. Animal Instinct

  • Humans possess freedom and rationality; animals act primarily by instinct.
  • Example: A dog biting someone when threatened is not held morally responsible because it acts on instinct. A human who intentionally harms another must answer for it because the act was freely chosen.
  • Key Point: Responsibility presupposes freedom.

3. Freedom and Responsibility

  • Having freedom means having the **burden of choice**. Every choice has consequences.
  • Example: A student freely cheats during exams; even if uncatchable by a teacher, they remain morally responsible for dishonesty.
  • Key Point: Freedom does not remove responsibility; rather, it demands responsibility.

4. Owning vs. Merely Abiding by Moral Standards

  • To be truly ethical, one must **have** moral standards, not merely comply with authority.
  • Merely abiding: Following rules because they are imposed by parents, teachers, or laws (e.g., "I won't steal because I'll get punished").
  • Owning: Internalizing the moral norm and making it part of one's conviction (e.g., "I won't steal because I value honesty and respect others' property").
  • Key Point: True morality begins when rules are internalized and followed even when no one is watching.

5. Legalism vs. Moral Responsibility

  • Legalism: Following rules blindly without reflection (e.g., "The law is hard, but it is the law" / *dura lex sed lex*).
  • Moral responsibility: Understanding the **spirit** behind the law and choosing it out of conviction (e.g., wearing a helmet because you value your life).
  • Key Point: Ethics requires self-affirmation and conviction, not just obedience.

Slide 1 & 2: Introduction & History of Athletics

Athletics is an exclusive collection of sporting events that involve competitive running, jumping, throwing, and walking (Slides 1 & 6).

Ancient History

  • Military Training: The ancient Greeks, Persians, and Romans used running as a core part of their military training (Slide 2).
  • First Olympic Games (776 B.C.): The only event of the first recorded Olympic Games in 776 B.C. was a foot race of approximately 205 yards (185 meters), known as the *stade* race (Slide 2).
  • Evolution of Field Events: Long jumping and javelin throwing were added soon after; these events developed naturally from hunting and war (Slide 3).

Slide 4 & 5: Evolution & Modernization

From the Dark Ages to Modern Era

  • The Dark Ages: There are few records of sports during the Dark Ages, but in England as early as the 12th century, accounts show the general population practicing events that gradually developed into modern track and field (Slide 4).
  • 18th & 19th Century England: Foot racing (sprinting and distance running) became widely popular in England in the latter half of the 18th century and first half of the 19th century (Slide 4).
  • Amateur vs. Professional: Traditionally, athletics was an amateur sport, but the opportunity to earn money has increased the level of competition today (Slide 5).
  • Training & Equipment Innovation: Improved training methods and new equipment have raised performance levels. For example, the Fosbury Flop adds about 15 centimeters to most high jumps; it was introduced by American high-jumper Dick Fosbury in the late 1960s (Slide 5).

Track & Field Definition & Venue (Slide 7 & 8)

Road Running (Slide 9)

  • The sport of running on a measured course over an established road.
  • Classified as long-distance running according to athletics terminology.
  • Distances typically range from **5 kilometers to 42.195 kilometers** in the marathon. May involve large numbers of runners or wheelchair entrants.

Cross Country Running (Slide 10)

  • A sport in which teams and individuals run a race on open-air courses over natural terrain.
  • Courses are typically **4–12 kilometers (2.5–7.5 miles)** long, including surfaces of grass, earth, woodlands, open country, hills, flat ground, and sometimes gravel road.
  • Judged on individual times and a points-scoring method for teams. Competed across all ages and genders, usually taking place during autumn and winter.

Slide 11: Race Walking

Race Walking Standards (Slide 11)

  • A long-distance athletic event. Although a foot race, it differs fundamentally from running in two strict rules:
    • 1. One foot must appear to be in contact with the ground at all times (no visible loss of contact to the human eye).
    • 2. The advancing leg must be straightened (not bent at the knee) from the moment of first contact with the ground until the vertical upright position.
  • Stride length is reduced; to achieve competitive speeds, race walkers must attain cadence rates comparable to Olympic 800-meter runners for hours at a time in events like the **20 km and 50 km** race walk.

Module 1: Nature & Scholarly Definitions of Communication

Communication is one of the most fundamental human activities. It is through communication that we share our thoughts, ideas, emotions, and aspirations with others, influencing the way we live, work, and relate to one another. In fact, communication is so deeply embedded in our daily lives that it often goes unnoticed, yet, without it, human existence as we know it would be impossible.

Scholarly Definitions

  • Pearson et al. (2011): Define communication as “the process of using messages to generate meaning.” Highlights the ongoing process and the ultimate goal of producing shared understanding.
  • Ober & Newman (2013): Describe communication as “the process of sending and receiving messages sometimes through spoken or written words and sometimes non-verbally through facial expressions, gestures and voice qualities.” Emphasizes multi-modal communication.
  • Jimenez & Alparo (2000): Define it broadly as “a process of sharing opinions and information, ideas and feelings.” Emphasizes the interpersonal dimension.
  • Wood (2012): Frames communication as “a systematic process in which people interact with and through symbols to create and interpret meanings.”
  • Baran (2011): Simplifies it to “the transmission of a source to a receiver,” reflecting the classical linear model.
  • Palta (2007): States that communication is “the process of sending information to oneself or another entity, usually via a language,” including intrapersonal communication.

Module 2: Key Concepts & Elements of Communication

From varying definitions, we extract four essential terms that form the backbone of communication theory:

  • Process: Implies continuity, movement, and change. The process never truly stops; it is dynamic and ongoing.
  • System: A set of interrelated parts that influence each other (micro-level internal systems and macro-level external cultural systems).
  • Symbols: Representations (arbitrary, abstract, and ambiguous) that stand for something else.
  • Meaning: The shared understanding between sender and receiver (Content Level vs. Relationship Level, Wood, 2012).

Elements of Communication (Pearson et al., 2011)

  • Sender (Source): Originator of the message who initiates and crafts it.
  • Message: The content transmitted (spoken, written, images, gestures).
  • Encoding: Transforming thoughts into a sendable format.
  • Channel (Medium): The pathway used to send the message.
  • Receiver: The audience who receives and interprets the message.
  • Decoding: Translating the message into meaning.
  • Feedback: The receiver's response indicating understanding.
  • Noise: Interference (Physical, Psychological, Semantic) that disrupts communication.

Module 3: Communication Models

1. Linear Model (One-Way)

  • Harold Lasswell’s Model (1948): Answers Who → Says What → In Which Channel → To Whom → With What Effect[cite: 5].
[Who / Speaker] ➔ [Says What / Message] ➔ [Channel] ➔ [To Whom / Audience] ➔ [Effect]

[Information Source] ➔ [Transmitter] ➔ [Channel + Noise Source] ➔ [Receiver] ➔ [Destination]

Improves on the linear model by adding feedback and introducing the Field of Experience (shared knowledge and background)[cite: 3].

Reflects real-life communication accurately where both participants are senders and receivers at the same time, co-creating meaning[cite: 2].

Module 4: Types of Communication (Mode, Context, Purpose, Style)

According to Mode

  • Verbal: Spoken (Oral) or Written communication using grammar and vocabulary.
  • Non-Verbal: Silent language making up 60–70% of communication (Kinesics, Proxemics, Paralanguage, Haptics, Chronemics, Appearance).
  • Visual: Graphs, charts, infographics, road signs, logos.
  • Digital / Multimodal: Social media, video conferencing, multimedia slides, emojis.

According to Context

  • Intrapersonal: Communication within oneself (self-talk, reflection).
  • Interpersonal: Direct interaction (Dyadic or Small Group).
  • Extended: Involving technology or mass media.
  • Organizational: Internal (memos, meetings) or External (press releases).
  • Intercultural: Between people of different cultural backgrounds.

According to Purpose and Style

  • Purpose: To Inform, To Persuade, To Entertain.
  • Martin Joos’ Five Styles (1962): Intimate, Casual, Consultative, Formal, Frozen.

Aspects of Globalization

  • Economic: Multinational corporations, free trade.
  • Cultural: Cross-border exchange of traditions, media, and music.
  • Political: International treaties, UN, WTO.
  • Technological: Internet, mobile communication, AI.
  • Social: Migration, international education.

Module 6: Hofstede’s Cultural Dimensions Theory

Geert Hofstede (1980) identified six dimensions that differentiate cultures:

  • Individualism vs. Collectivism: Individualist (independence, U.S.) vs. Collectivist (group harmony, Philippines).
  • Power Distance: High (accept hierarchy) vs. Low (value equality).
  • Uncertainty Avoidance: High (prefer strict rules) vs. Low (embrace ambiguity).
  • Masculinity vs. Femininity: Masculine (competitiveness) vs. Feminine (cooperation, quality of life).
  • Long-Term vs. Short-Term Orientation: Long-term (persistence, thrift) vs. Short-term (traditions, quick results).
  • Indulgence vs. Restraint: Indulgent (value leisure, fun) vs. Restrained (self-control, discipline).

Module 7: Varieties and Registers of Spoken & Written Language

Language Varieties ("Lect")

  • Dialects: Regional or social varieties (e.g., British vs. American English).
  • Sociolects: Defined by social class, age, or occupation (e.g., medical jargon).
  • Ethnolects: Associated with specific ethnic groups (e.g., AAVE).
  • Idiolects: An individual's unique way of speaking.

The Five Language Registers (Martin Joos)

  • Frozen Register: Static, ritualistic, archaic (e.g., National Anthem, wedding vows).
  • Formal Register: Structured, impersonal, avoids slang (e.g., Academic lectures, business reports).
  • Consultative Register: Semi-formal, two-way, expert-client interaction (e.g., Doctor-patient consultation).
  • Casual Register: Informal among peers, uses slang and contractions (e.g., Text messages with friends).
  • Intimate Register: Private, between deep personal relationships.

Chapter 1: Republic Act No. 1425 (The Rizal Law)

Introduction to the Course: Republic Act 1425 mandates the inclusion of the life, works, and writings of Jose Rizal in all school curricula.

Enactment, Authorship & Bills

  • Enactment Date: Enacted on June 12, 1956.
  • Authorship: Sponsored and authored mainly by Senators Jose P. Laurel and Claro M. Recto.
  • Senate Bill No. 438: Submitted on April 3, 1956, and presented by Senator Jose P. Laurel on April 17, 1956.
  • House Bill No. 5561: A similar bill filed by Congressman Jacobo Z. Gonzales.
  • Final Approval: Both bills were unanimously approved on May 12 and 14, 1956, and signed into law by President Ramon Magsaysay on June 12, 1956.

Controversies and Opposition

  • Legislative and Church Opposition: Fiercely opposed by members of the Legislative Branch and the Catholic Church because the compulsory reading of Rizal's novels was viewed as humiliating to Catholic dogmas.
  • Opposing Senators: Opposed by three senators: Francisco Rodrigo, Mariano Cuenco, and Decoroso Rosales.
  • CBCP Stance: The Catholic Bishops Conference of the Philippines (CBCP) argued it violated Canon Law 1399, which forbids or bans books that attack or ridicule Catholic doctrine and practices.

Approved Amendments (The Compromise)

  • Senator Laurel: Included other works by and about Rizal alongside the two novels, and restricted compulsory reading of unexpurgated versions strictly to the college level (elementary and secondary levels were exempted from unexpurgated versions).
  • Senator Lim: Suggested exemptions for students who felt reading Rizal's novels would negatively affect their religious faith.
  • Senator Primicias: Promulgated rules requiring a written statement or affidavit for exemption from reading the novels (though not from taking the Rizal course itself).

Key Sections of Republic Act No. 1425

  • Section 1: Inclusion of Rizal's life, works, and writings (particularly Noli Me Tangere and El Filibusterismo) in all school curricula (public or private), requiring original/unexpurgated English texts in collegiate courses.
  • Section 2: Obligation of all school libraries to keep an adequate number of copies of original and unexpurgated editions, approved biographies, and other writings.
  • Section 3: Translation of works into English, Tagalog, and principal dialects, printed in cheap, popular editions, and distributed free of charge through Purok organizations and Barrio Councils.
  • Section 4: Prohibiting public school teachers and other persons from discussing religious doctrines remains unaffected (nothing shall construe as amending or repealing Section 927 of the Administrative Code).
  • Section 5: Appropriation of 300,000 pesos to carry out the Act.
  • Section 6: Immediate effect upon approval.

Objectives, Goals & Acquired Traits

  • Objectives: Rededicate youth to freedom and nationalism for which heroes lived and died; pay tribute to Rizal for shaping the Filipino character; gain an inspiring source of patriotism.
  • Goals: Recognize relevance of Rizal's ideals to present conditions; apply ideas in daily life; develop understanding of Rizal's character; foster moral character, personal discipline, citizenship, and vocational efficiency.
  • Traits Acquired by Youth: Incorruptible, direction, determination, patriotism, confidence, courage, and nationalism.

Patriotism vs. Nationalism

  • Patriotism: The love someone feels for their country based on the idea that this country itself is good and that good people live there (positive connotation).
  • Nationalism: Love and affection for one's country based on the idea that this particular country is better than all the rest.

National Hero Context

  • Official Status: Rizal is NOT the official legislated national hero of the Philippines. No law, executive order, or proclamation has been officially enacted proclaiming any historical figure as national hero.
  • Criteria (Dr. Otley H. Beyer & NCCA): Must be a Filipino; peace-loving and pacifist; great sense of patriotism; must die for country as a martyr.
  • NCCA Official Candidates: Jose Rizal, Andres Bonifacio, Emilio Aguinaldo, Apolinario Mabini, Marcelo H. Del Pilar, Sultan Dipatuian Kudarat, Juan Luna, and Melchora Aquino.
  • Honors Accorded to Rizal: Commemorated on birth and execution days; highest number of monuments; name is a household word; images on postage stamps and widest circulation coins/paper money; streets and institutions named after him.

Chapter 2: The Philippines in the 19th Century

Spain and the Philippines in Rizal's Time: Spanish rule was imposed by conquest. Miguel Lopez de Legazpi established the first Spanish settlement in Cebu in 1565. Before conquest, indigenous peoples had their own government in barangays headed by a native chieftain called a "datu".

Political Condition

  • National Government: Headed by the Governor-General (chief executive, head of state and church, commander-in-chief of the military, holding cumplase power). Checked by the Visitador (administrator checker) and Residencia (investigating body).
  • Provincial Government: Headed by the Alcalde Mayor (corrupt administrator holding executive, judicial, and military powers limited to the province).
  • Municipal Government: Headed by the Gobernadorcillo (town level, holding indulto de comercio trading rights).
  • Barrio Government: Headed by the Cabeza de Barangay.
  • Local Position Qualifications: Male, 23 years old, educated, and owning property worth 500 pesos.

Supremacy of the Friars (Frailocracy) & Abuses

  • Frailocracy (Frailocracia): Spanish political philosophy of union of Church and State where regular Spanish priests dominated parishes and controlled political, religious, and educational life.
  • Corrupt Spanish Officials:
    • General Rafael de Izquierdo (1871–1873): Ruthless governor who executed the Gomburza (Fathers Mariano Gomez, Jose Burgos, and Jacinto Zamora, the "Martyrs of 1872").
    • Admiral Jose Malcampo (1874–1877): Inept and weak administrator.
    • General Fernando Primo de Rivera: Enriched himself by accepting bribes from Manila gambling casinos.
    • General Valeriano Weyler (1888–1891): Scornfully called "tyrant" by Filipinos and "The Butcher" by Cubans.
    • Admiral Camilo de Polavieja (1896–1897): Heartless governor detested for executing Dr. Jose Rizal.

Philippine Representation in the Spanish Cortes

Three periods of representation occurred (1810–1813, 1820–1823, and 1834–1837) before overseas representation was abolished in 1837, worsening Philippine conditions.

Socio-Cultural Condition & Social Stratification

  • Peninsulares: Spaniards born in Spain living in the Philippines (highest class).
  • Insulares: Spaniards born in the Philippines.
  • Creoles: Mixed blood / combination of Spanish and Filipino.
  • Illustrados: Well-educated Filipinos.
  • Principalia: Landowners.
  • Indios: The unfortunate and discriminated native class.

Educational System During the Spanish Regime

  • Religion was the center of education. Separate schools and curriculums for boys and girls.
  • Male Secondary Schools: Colegio Maximo de San Ignacio (1589), College of San Ildefonso (1599), Ateneo Municipal (1817). Curriculum: Spanish History, Latin, Philosophy, Canon Law, Civil Law, Rhetoric.
  • Female Secondary Schools: Colegios of Santa Potenciana (1591), Sta. Isabel (1632), Santa Catalina de Sena (1696), Santa Rita College (1719), Collegio de la Inmaculada Concepcion Concordia (1868). Curriculum: Rules of courtesy, Vocal Music, Language, and Sewing.
  • University Level: University of Santo Tomas (UST) was the only university-level institution in Manila at the end of the period, established in 1611.
  • Key Decrees: Educational Decree of 1863 (established primary schools for boys and girls in each major town with Spanish as medium); Moret Decree of 1870 (intended to secularize higher education, opposed by friars).

Economic Conditions and Socio-Economic Policies

  • Encomienda System: A grant of inhabitants given to Spanish colonizers. Types: Royal, Ecclesiastical, and Privado. Later converted into Haciendas owned by religious orders.
  • Reducción: Resettlement policy to easily monitor natives and convert them to Catholicism.
  • Bandala: Compulsory sale of native products to the Spanish government.
  • Polo y Servicios: Forced labor for all Filipino males aged 16–60 for 40 days (reduced to 15 days in 1884). Avoided by paying the falla fee. Laborers were called polistas.
  • Taxation: Cedula (identity tax for 18+), Sanctorum (church tax), Donativo de Zamboanga (tax for conquest of Jolo), Tribute / Tributo (paid in cash or kind).
  • Galleon Trade: Monopoly trading system utilizing boletas (tickets).
  • Guardia Civil: Created by Royal Decree in 1852 (amended 1888) to maintain internal peace; became a symbol of tyranny and abuse.

Chapter 3: Rizal’s Family, Childhood, and Early Education

The Ancestry of Rizal

  • Paternal Ascendants: Domingo Lam-co (full-blood Chinese from Amoy, China, came in mid-17th century, married Inez dela Rosa, took the name Mercado) $\rightarrow$ Francisco Mercado $\rightarrow$ Juan Mercado $\rightarrow$ Francisco Rizal.
  • Maternal Ascendants: Eugenio Ursua $\rightarrow$ Benigna $\rightarrow$ Regina $\rightarrow$ Brigida $\rightarrow$ Teodora Alonso.

Birth and Baptism

  • Birth: Dr. Jose Protacio Rizal Mercado y Alonso Realonda was born on June 19, 1861 (Wednesday, between 11:00 PM and midnight) in Calamba, Laguna.
  • Baptism: Baptized on June 22, 1861, by Fr. Rufino Collantes (who remarked: "Take good care of this child, for someday he will become a great man"). Godfather: Fr. Pedro Casana.

Profiles of Parents & Siblings

  • Francisco Mercado Rizal (1818–1898): Born in Biñan; studied Latin and Philosophy at College of San Jose; hardworking tenant-farmer; called by Rizal "a model of fathers".
  • Teodora Alonso Realonda (1826–1911): Born in Sta. Cruz, Manila; studied at Colegio de Sta. Rosa; possessed refined culture, literary talent, business ability, and Spartan fortitude.
  • The 11 Siblings: Saturnina, Paciano (second child, closest brother, general of revolution), Narcissa, Olympia, Lucia, Maria, Jose (Pepe), Concepcion (Concha, died at 3, Rizal's first sorrow), Josefa (epileptic, Katipunan member), Trinidad, and Soledad.
  • Family Status: Belonged to the middle class / principalia / creoles class; owned a large 2-story house, vast private library (over 1,000 books), carriage, and horses.

Childhood Memories & Early Works

  • Childhood Highlights: Nursemaid (aya) ghost/fairy stories; daily Angelus; nocturnal walks; death of sister Concha; reading Spanish Bible at age five with mother; "The Story of the Moth" (making a profound impression about dying a martyr to illusions); early sketching and clay/wax modeling.
  • Literary Beginnings: Wrote his first native language poem, Sa Aking Mga Kabata (To My Fellow Children), at age eight, revealing early nationalist sentiment.

Early Education in Calamba and Biñan

  • Tutors in Calamba: Maestro Celestino, Maestro Lucas Padua, and Leon Monroy (former classmate of his father who taught Spanish and Latin before dying 5 months later).
  • Studies in Biñan: Sent in June 1869 under Maestro Justiniano Cruz (used corporal punishment). Took painting lessons under Juancho.
  • Return to Calamba: Returned home in December 1870 via the steamer Talim.

Chapter 4: Rizal’s Higher Education

Formal Education at Ateneo Municipal

  • Admission: Entered Ateneo at age 11 (June 1872), 4 months after Gomburza execution while mother was in prison. Passed entrance exam at San Juan de Letran on June 10, 1872. Initially rejected by registrar Fr. Magin Fernando for being late, undersized, and frail, but admitted through Manuel Burgos's intervention.
  • Boarding House: Boarded on Caraballo Street (owned by Titay, from whom the family collected a 300-peso debt), later moved to No. 6 Magallanes Street in Intramuros.
  • Atenean System: Rigid discipline, morning masses, and the Empire System dividing students into Romans (boarders) and Carthaginians (non-boarders) with ranks: emperor, tribune, decurion, centurion, standard bearer.
  • Academic Performance by Year:
    • First Year: Professor Fr. Jose Bech. Started at bottom of class; took private Spanish lessons at Santa Isabel College; achieved excellent grades and a religious prize.
    • Second Year: Excellent grades, won a medal in Latin.
    • Third Year: Became an interno (boarder), won five medals.
    • Fourth Year: Inspired by Padre Francisco de Paula Sanchez to write poetry and study harder.
    • Last Year: Graduated on March 23, 1877, with a Bachelor of Arts (Bachiller en Artes) degree with highest honors.
  • Extracurriculars & Art: Sodality of Our Lady, Apostleship of Prayer, Academy of Spanish Literature; studied painting under Agustin Saez and sculpture under Romualdo de Jesus (carved Virgin Mary and Sacred Heart).
  • Literary Works at Ateneo: Mi Primera Inspiracion (dedicated to mother), Un Cuerdo de Mi Pueblo (homage to Calamba), Al Niño Jesus, Through Education The Country Receives Light, and The Intimate Alliance Between Religion and Good Education. Favorite novel: The Count of Monte Cristo by Alexander Dumas.

Education at the University of Santo Tomas (UST)

  • Enrollment: Enrolled in Philosophy and Letters initially (father's choice / absence of Father Ramon Pablo's advice). Later shifted to Medicine to cure his mother's failing eyesight upon advice from Father Ramon Pablo.
  • Academic Struggles & Environment: Unhappiness caused by hostility of Dominican professors, racial discrimination against Filipino students, and obsolete/repressive instruction (physics taught without letting students touch apparatus). Youthful distractions included infatuations with Segundina Katigbak, Leonor Valenzuela, and Leonor Rivera.
  • Literary Achievements: Won contests at Liceo Artistico Literario de Manila: A La Juventud Filipina (To the Filipino Youth — first great Spanish poem by a Filipino recognizing youth as "fair hope of the motherland") and El Consejo de los Dioses (The Council of the Gods — allegory praising Cervantes; grand prize awarded to Spaniard upon discovering author was a Filipino). Also wrote Junto al Pasig and A Filipinas.
  • Student Activism: Formed secret society Compañerismo (Companions of Jehu) with Galicano Apacible to protest discrimination and archaic teaching methods.
  • First Taste of Spanish Brutality: Assaulted with a sword by a Guardia Civil lieutenant during a dark night in Calamba for failing to greet him (Buenas noches). Formal complaint to Governor-General Primo de Rivera resulted in no justice.

Decision to Go to Europe

After completing his 4th year in medical school, Rizal secretly planned to leave for Europe. Orchestrated with Paciano, the real purposes were to make a name in journalism, observe European society, and prepare to liberate Filipinos from Spanish tyranny.
